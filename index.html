🌹 Photorealistic Simulation

          

            Features 25+ layered petals arranged in Fibonacci phyllotaxis whorls with Bézier edge ruffling, radial subsurface scattering gradients, botanical sepals, thorned stem, golden stamens, and glistening dew drops.
          

        


        

          
⚡ 60 FPS True-Color ASCII

          

            Perceptual human luminance mapping (0.2126R + 0.7152G + 0.0722B) with 24-bit RGB character reproduction, monospace aspect ratio compensation, and zero-dependency Canvas glyph blitting.
          

        


        

          
🚀 Launching on GitHub Pages

          

            This project is 100% standalone vanilla HTML5/JS without any build tools needed. Push to GitHub and enable Pages:
          

          

            git push origin main
          

          

            Go to Settings → Pages → Branch: main → / (root) → Save.
